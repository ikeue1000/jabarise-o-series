# jabarise-o-series

株式会社じゃばらいず北山｜ふるさと納税シリーズ

---

## 概要

24自治体のふるさと納税業務受託における、請求・経費・支払管理を標準化するシステム群。

担当者ごとの処理ばらつきを排除し、同じデータ・同じマスタ・同じルールで処理し、間違いが表に出る状態を作ることが目的。

---

## システム構成

```
ふるさと納税シリーズ
├─ 共通基盤        共通マスタ・取込データ・監査ログ
├─ Billo          自治体請求管理
├─ Costo          経費・返礼率管理
├─ Payo           事業者支払管理
└─ Henreio        返礼品管理（別プロジェクト・連携のみ）
```

基本方針：**アプリは分ける。マスタとデータは分けない。**

## 技術構成

DBはConoHa VPS上のPostgreSQLを前提とする。
ただし、PostgreSQLのインストール・設定・サーバー操作は、池上確認後に実施する。
Manusは勝手にサーバー操作しない。
